# The Fold

Static webpage for The Fold daily newsletter.

- Latest edition: `index.html`
- Archive: `archive/2026/`
- Legacy uploaded edition: `the-fold-3-april-2026.html`
- Feed configuration: `feeds.json`
- Editorial style: `EDITORIAL_STYLE.md`
- Automation notes: `AUTOMATION.md`

This repository can be served with GitHub Pages from the `main` branch root.
